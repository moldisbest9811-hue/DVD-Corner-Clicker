# Logo artwork credits

The game bundles the following original SVG logo artwork locally so the bouncing
screen does not depend on third-party image hosts at runtime:

- DVD: derived from the DVD logo artwork bundled by ecklf/lg-luma; original source
  is Wikimedia Commons, https://commons.wikimedia.org/wiki/File:DVD_logo.svg
- Blu-ray Disc: original Wikimedia Commons artwork,
  https://commons.wikimedia.org/wiki/File:Blu-ray_Disc.svg
- Philips: Philips logo artwork from philips-labs/about-this-organization,
  images/Philips_logo.svg
- VHS: JVC VHS logo artwork; original source is Wikimedia Commons,
  https://commons.wikimedia.org/wiki/File:VHS_logo.svg

All marks remain the property of their respective trademark owners. They are
included only to identify the corresponding media formats and brands. No
endorsement or affiliation is implied. The HD DVD and Compact Disc logos still
use their Wikimedia-hosted SVG sources.
